# Design catalogue (the team's 120 styles, sorted)

The original list mixes visual styles, layout patterns, interaction techniques, duplicates and styles
meant for software products. It is sorted below so a design can be built as
**visual style + layout pattern + interaction pattern**. Original numbers are kept so the team can
keep saying "#97".

Tags: **fit** = good match for wellness, retreat, villa or yoga clients · **caution** = needs extra QA for
overlap or readability · **blocked** = only when the user asks · **overused** = already common in the registry.
